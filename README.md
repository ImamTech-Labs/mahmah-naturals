# MahMah Naturals

An online cosmetics store for MahMah Naturals, featuring skincare, body care, soaps, and oils.

## Current stage

This repository contains the first responsive storefront design. The product shelf is intentionally a placeholder until the shop's real product names, photos, prices, sizes, and stock details are supplied.

The planned order flow is:

1. Browse the collection and add products to a bag.
2. Chat with the shop owner to confirm availability and delivery cost for the customer's location.
3. Return to checkout and pay online.
4. The owner delivers the order personally across Nigeria.

The WhatsApp contact and online payment provider still need to be connected before orders can be placed. Delivery fees will be confirmed by the owner before payment.

## Preview locally

Open `index.html` in a browser. The current version uses plain HTML, CSS, and JavaScript, so it does not need a package installation.

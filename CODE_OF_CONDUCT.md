# Code of Conduct

## Our commitment

MahMah Naturals is a community project maintained by ImamTech Labs. We want participation to be respectful, constructive, inclusive, and focused on improving the project.

## Expected behaviour

- Be respectful and considerate.
- Give clear, helpful, and constructive feedback.
- Welcome people with different experience levels.
- Focus criticism on ideas and code, not people.
- Respect privacy. Do not publish customer information, credentials, or private communications.
- Accept responsibility for mistakes and correct them when possible.

## Unacceptable behaviour

Harassment, discrimination, personal attacks, intimidation, deliberate disruption, and sharing another person's private information without permission are not acceptable.

## Maintainer responsibilities

Project maintainers may edit or remove unacceptable contributions, close discussions, or restrict participation when needed to keep the project safe and productive.

## Reporting

Report conduct concerns privately to the repository maintainers through the ImamTech Labs GitHub organisation. Avoid posting sensitive personal details in public issues.

This code of conduct applies to repository issues, pull requests, reviews, discussions, and other project spaces.
